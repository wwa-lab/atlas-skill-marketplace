# Product Sources

- `Atlas_Marketplace_PRD_v0.3.md` is the current product requirement source and
  records the IBM iSeries RPGLE pilot decisions.
- `Atlas_Marketplace_PRD_v0.2.md` is retained as the historical baseline.
- `prototypes/atlas_marketplace_v2_6_mvp_plus_day2.html` is the supplied visual
  and interaction reference.

The prototype covers a high-fidelity Discover landing page, simplified Skill
detail modal, theme switch, search, and phase filtering. It does not implement
the complete MVP lifecycle, authentication, registration, version management,
local installation, update, rollback, uninstall, feedback, or administration.

When sources conflict, follow `PROJECT_RULES.md`: an approved active feature
spec takes precedence, followed by PRD v0.3 and durable product decisions. The
prototype never promotes a Day 2 or fixture-backed surface into the pilot.
