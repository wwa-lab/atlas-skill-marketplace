# Architecture Decision Records

ADRs capture durable choices that cross feature or runtime boundaries. Feature
scope remains in `specs/`; an ADR explains why a technical or governance choice
was made and what it constrains.

Use `NNNN-short-kebab-title.md` and copy `_template.md`. Accepted ADRs are
immutable records; supersede them with a new ADR instead of rewriting history.

Initial ADR candidates are listed in `docs/context/open-questions.md`.
